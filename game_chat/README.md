# Word Search: Evolution

A dynamic and responsive Flutter Word Search game featuring multiple modes, animations, and premium UI.

## Features
- **Multiple Game Modes**: Level-based, Infinite, Daily Puzzle, and Category Themes.
- **Premium UI/UX**: Custom animations, floating titles, and glassmorphism-inspired designs.
- **Fully Responsive**: Adapts to various screen sizes and orientations.
- **Sharing**: Integrated sharing functionality to invite friends.
- **Sound Management**: Full control over background music and sound effects.

## Getting Started
To run this project:
1. Ensure you have Flutter installed.
2. Clone the repository.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Built With
- **Flutter** & **Dart**
- **GetX** (State Management)
- **Share Plus** (Sharing)
- **Sound Manager** (Custom Audio Service)
